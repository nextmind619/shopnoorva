## خطوات إنشاء الفيديو (أنت)

### 1) التحضير
- [ ] حمّل الصور من المشروع أو صوّر **3–4 لقطات قصيرة** (15 ث كحد أقصى للمونتاج): منتج، استعمال، قفل العجلات، الهدية.
- [ ] جهّز نص السكريبت (جدول فوق).
- [ ] اختر موسيقى ترند **بدون كلمات** أو خفيفة (Reels → Audio).

### 2) CapCut (جوال أو PC) — موصى به
1. مشروع جديد **9:16**.
2. استورد Clips + الصور.
3. رتّب حسب الجدول (مشهد = 2.5–3.5 ث).
4. **Transitions:** «Flash» أو «Mix» سريع بين المشاهد (0.2–0.3 ث).
5. **Text:** خط عربي غليظ (Cairo / Tajawal)، أبيض + outline أسود، أسفل أو وسط الشاشة.
6. **Auto captions** إذا سجّلت VO بالدارجة.
7. آخر مشهد: مستطيل أخضر أو بنفسجي + «اطلب دابا — COD».
8. Export **1080p · 30fps · MP4**.

### 3) Instagram Reels
1. Reels → Upload أو Montage من CapCut.
2. أضف **موسيقى ترند** من المكتبة (لا ترفع موسيقى محمية).
3. Cover: `02-premium-hero` + نص «399 درهم COD».
4. Caption:
   ```
   طاولة لابتوب متحركة 🖥️ ارتفاع + عجلات + هدية حقيبة USB 🎁
   399 درهم · الدفع عند الاستلام · توصيل مجاني 🇲🇦
   👇 الرابط فالبio
   #المغرب #الدار_البيضاء #workfromhome #laptop #noorva
   ```
5. Sticker **Link** (إن متاح) → صفحة المنتج.

### 4) TikTok
- نفس الفيديو، caption قصير + `#COD #Morocco #desksetup`.
- رابط المنتج في Bio.

### 5) قبل النشر
- [ ] أول 2 ثواني واضحة (Hook).
- [ ] الثمن و COD ظاهرين.
- [ ] الرابط أو «رابط فالبio» مذكور.
- [ ] جودة نص مقروء على جوال صغير.
